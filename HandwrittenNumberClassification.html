Handwritten Number Classification

Multi-layer perceptron neural network trained on the MNIST dataset to recognize handwritten digits. Implements feedforward and backpropagation algorithms from scratch using NumPy.

Overview

Classic neural network implementation for digit recognition using the MNIST dataset. The multi-layer perceptron learns to classify 28×28 grayscale images of handwritten digits (0-9) through supervised learning with gradient descent optimization.

Features

  • Fully connected neural network with configurable hidden layers
  • Backpropagation with gradient descent optimization
  • Softmax output layer for probability distribution over classes
  • Cross-entropy loss function
  • Training and validation accuracy tracking

Network Architecture

Input Layer:  784 neurons (28×28 flattened image)
Hidden Layer: 128 neurons (ReLU activation)
Hidden Layer: 64 neurons (ReLU activation)
Output Layer: 10 neurons (Softmax activation)

Total Parameters: ~100,000
Optimizer: Stochastic Gradient Descent (SGD)
Loss: Cross-Entropy

Implementation Details

  • Forward Pass: Matrix multiplication through layers with activation functions
  • Backward Pass: Gradient computation via chain rule and backpropagation
  • Weight Updates: Gradient descent with configurable learning rate
  • Data Processing: Pixel normalization (0-1 range) and one-hot encoding for labels
  • Validation: Separate test set for unbiased accuracy measurement

Tech stack

• Python 3.x
• NumPy
• Matplotlib (visualization)
• MNIST dataset

Dataset

Training: 60,000 images
Testing: 10,000 images
Classes: 10 (digits 0-9)
Format: 28×28 grayscale

Key Concepts

  • Feedforward: Forward propagation through network layers
  • Backpropagation: Gradient computation for weight updates
  • Softmax: Converts logits to probability distribution
  • Cross-Entropy: Loss function for classification
