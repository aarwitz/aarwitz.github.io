How It Works

  • 1. When you click an external link, the system queries Archive.org's Wayback Machine API
  • 2. It finds the most recent archived snapshot of that URL
  • 3. The archived content is fetched and displayed in a modal preview
  • 4. A banner shows the archive date, so you know you're viewing a snapshot
  • 5. Click again (or the "Visit Full Page" button) to go to the live site

Note: Open your browser's console to see detailed logging of the Archive.org API calls.
