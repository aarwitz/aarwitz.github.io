Reinforcement Learning & PPO Derivations

From Value Functions to Policy Optimization

December 5, 2025

1. RL Basics

Policies

The purpose of RL is to create a function that maps states to actions. So, given a state, the policy will choose an action. We call this function a "policy". Worth mentioning that (usually) the policy doesn't actually create a deterministic mapping from states to actions, but rather a probability distribution over actions given a state.

$$\pi(a|s): S \to A$$

Value Functions

We create a Value function to try to quantify how good a policy is. We define this value $V$ of a policy $\pi$ to be the sum of its discounted expected rewards starting from state $s$.

$$V^\pi(s) = \mathbb{E}_\pi\left[R(s_0) + \gamma R(s_1) + \gamma^2 R(s_2) + \cdots \mid s_0 = s\right]$$

$$= \mathbb{E}_\pi\left[\sum_{t=0}^{\infty} \gamma^t R(s_t) \mid s_0 = s\right]$$

where $\gamma \in [0,1]$ is the discount factor that determines how much we value future rewards relative to immediate rewards.

Bellman Equation

The Bellman equation provides a recursive definition of the Value function using transition probabilities. The transition probability $P(s'|s,a)$ represents the probability of reaching state $s'$ when taking action $a$ from state $s$. Note this is different from the policy probability mentioned earlier ($\pi(a|s)$). In deterministic environments, the transition probability is either 0 or 1, indicating a certain next state, because the environment's dynamics are fully predictable and so taking action $a$ from state $s$ always leads to state $s'$.

$$V^\pi(s) = \sum_{a} \pi(a|s) \left[R(s,a) + \gamma \sum_{s'} P(s'|s,a) V^\pi(s')\right]$$

In words:

  • The value at state $s$ is the expected immediate reward
  • Plus the discounted expectation over values of all possible next states
  • Each next state weighted by its transition probability
  • Averaged over all actions according to the policy $\pi$

Key Insight:

Because the Bellman equation is recursive, defining the value of any state requires defining the value of all states reachable from it. This recursion typically propagates through the entire state space, giving us values for all states under policy $\pi$.

2. Optimal Policies and Value Functions

The optimal value function $V^*(s)$ is the maximum value achievable from state $s$ under any policy:

$$V^*(s) = \max_\pi V^\pi(s)$$

The optimal policy $\pi^*$ is the policy that achieves this maximum value for all states:

$$\pi^* = \arg\max_\pi V^\pi(s) \quad \forall s \in S$$

The Bellman Optimality Equation characterizes the optimal value function:

$$V^*(s) = \max_a \left[R(s,a) + \gamma \sum_{s'} P(s'|s,a) V^*(s')\right]$$

3. Advantage Function

Advantage Function

As you might expect, the goal then is to find the optimal policy, so we begin by defining a way of comparing policies. The Advantage Function measures how much better it is to take a specific action $a$ in state $s$, instead of what the policy would normally do, and then only afterwards following the policy, compared to just following exactly the policy $\pi$ from the start.

$$A^\pi(s,a) = R(s,a) + \gamma \sum_{s'} P(s'|s,a) V^\pi(s') - V^\pi(s)$$

Interpretation:

  • If $A^\pi(s,a) > 0$: Taking action $a$ is better than the average action under $\pi$
  • If $A^\pi(s,a) < 0$: Taking action $a$ is worse than the average action under $\pi$
  • If $A^\pi(s,a) = 0$: Taking action $a$ is equivalent to following $\pi$

Equation explained:

  • The Advantage Function's first term $r(s,a)$ represents the immediate reward for taking action $a$ in state $s$.
  • The second term is the discounted expected future value of following policy $\pi$ after taking action $a$ in state $s$.
  • The third term subtracts the baseline value $V^\pi(s)$, representing the expected value of following policy $\pi$ from the beginning, state $s$.

4. Policy Parameterization

In practice, state and action spaces can be enormous (or even continuous). We cannot explicitly store a probability $\pi(a|s)$ for every state-action pair.

Solution: We parameterize the policy with parameters $\theta$ (e.g., neural network weights):

$$\pi_\theta(a|s)$$

Now instead of optimizing over all possible policies, we optimize over the parameter space $\theta$ to find the best policy.

Policy Gradient Objective

We want to maximize the expected return under the parameterized policy:

$$J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta}\left[\sum_{t=0}^{T} \gamma^t R(s_t, a_t)\right]$$

where $\tau = (s_0, a_0, s_1, a_1, \ldots)$ is a trajectory sampled from policy $\pi_\theta$

5. Proximal Policy Optimization (PPO)

Proximal Policy Optimization (PPO) is a policy gradient method that aims to improve the policy while preventing overly large updates that could destabilize training.

The Core Idea

PPO uses the Advantage function to determine which actions to reinforce. The key insight is:

  • If $A^\pi(s,a) > 0$, we want to increase the probability of taking action $a$ in state $s$
  • If $A^\pi(s,a) < 0$, we want to decrease the probability of taking action $a$ in state $s$

Policy Ratio

PPO defines a probability ratio between the new policy $\pi_\theta$ and the old policy $\pi_{\theta_{\text{old}}}$:

$$r_t(\theta) = \frac{\pi_\theta(a_t|s_t)}{\pi_{\theta_{\text{old}}}(a_t|s_t)}$$

PPO Objective (Clipped)

The clipped PPO objective prevents the policy from changing too much in a single update:

$$L^{\text{CLIP}}(\theta) = \mathbb{E}_t\left[\min\left(r_t(\theta) A_t, \text{clip}(r_t(\theta), 1-\epsilon, 1+\epsilon) A_t\right)\right]$$

where:

  • $A_t = A^{\pi_{\theta_{\text{old}}}}(s_t, a_t)$ is the advantage estimate
  • $\epsilon$ is a hyperparameter (typically 0.1 or 0.2)
  • $\text{clip}(x, a, b)$ clips $x$ to the range $[a, b]$

Why Clipping?

The clipping mechanism ensures that the policy doesn't change too drastically in a single update. If the ratio $r_t(\theta)$ deviates too far from 1 (meaning the new policy is very different from the old one), the objective stops incentivizing further change. This creates a "trust region" that leads to more stable training.

Summary: The Path to PPO

1. Policy: $\pi_\theta(a|s)$ defines action probabilities for each state

2. Value Function: $V^\pi(s)$ measures expected discounted returns under policy $\pi$

3. Advantage Function: $A^\pi(s,a) = Q^\pi(s,a) - V^\pi(s)$ tells us how good action $a$ is relative to average

4. PPO: Uses advantages to update policy parameters $\theta$ while clipping prevents overly large updates
