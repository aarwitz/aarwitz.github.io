Project overview

The OpenAI Gym CarRacing environment is a game where keyboard input is used to drive a car around a racetrack. The environment provides a reward at each timestep based on how much new track is covered, with penalties for going off-track. The goal is to maximize the total reward by completing laps as quickly and efficiently as possible.

RL is a lot easier to implement, but the real world does not come with reward functions, so a lot of my effort has gone into improving the imitation learning network using DAgger. I actually find the game difficult to achieve a high score on myself. So, I also trained a policy using RL to create the expert demonstrations used to train my imitiation learning network. The RL agent achieves a score of about 780 out of a maximum possible 1000. The imitation learning agent achieves a score of about 600, but continues to get better as I improve the network and demonstration data.

Convolutional neural network designed for vision-based control:

CNN Layers

Input: (3, 96, 96) RGB image from CarRacing environment

Conv2D(3→8, kernel=3, stride=1, padding=1) + LeakyReLU(0.2)
Conv2D(8→16, kernel=3, stride=1, padding=1) + LeakyReLU(0.2)
Conv2D(16→32, kernel=3, stride=1, padding=1) + LeakyReLU(0.2)

Flatten
Fully Connected(294,912 → 512) + LeakyReLU(0.2)
Fully Connected(512 → 9) → Softmax

Output: 9-class action probabilities

Training Details

Optimizer: Adam (lr=1e-2)
Loss: Cross-entropy
Batch size: 64
Epochs: 100
Data: Expert demonstrations from keyboard control
Action mapping: Continuous actions → 9 discrete classes

Interactive system for collecting training data:

# Record expert demonstrations
python main.py teach

# Controls:
# Arrow keys: Steer left/right, gas, brake
# SPACE: Restart on a new track
# TAB: Save the current run
# ESC: Quit

# Data is saved as:
# observation_00000.npy, observation_00001.npy, ...
# action_00000.npy, action_00001.npy, ...

Each demonstration run captures synchronized observation-action pairs, automatically saved when pressing TAB for high-quality recordings.

DAgger Implementation

The project includes scaffolding for DAgger (Dataset Aggregation), an iterative imitation learning algorithm that improves upon behavioral cloning by:

  • Training an initial policy on expert demonstrations
  • Rolling out the learned policy to collect new states
  • Querying the expert for optimal actions at visited states
  • Aggregating new data with original dataset
  • Retraining to handle distribution shift

Status: DAgger implementation scripts and integration in progress.

Reinforcement Learning Alternative

The project also includes a complete PPO (Proximal Policy Optimization) implementation in the rl_approach/ folder, demonstrating an alternative approach that learns from environmental rewards rather than expert demonstrations.

PPO Features

  • Actor-critic architecture with shared CNN backbone
  • Frame stacking (4 frames) for temporal information
  • GAE (Generalized Advantage Estimation)
  • Reward shaping and off-track detection
  • Comprehensive training and evaluation pipeline
# Train with reinforcement learning
cd rl_approach
python main.py train

# Evaluate trained RL agent
python main.py evaluate

See rl_approach/WHY_RL.md for detailed comparison between imitation learning and reinforcement learning approaches.

  • rl_approach/environment.py — environment wrapper with preprocessing
