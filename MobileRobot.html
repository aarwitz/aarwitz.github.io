Overview

CleaningRobot is a robotic vision pipeline enabling autonomous object detection and navigation. The system detects objects (dirt, socks, debris) in 3D space using YOLOv8 on NVIDIA hardware, estimates accurate poses via depth sensing, and provides real-time visualization for navigation planning.

Architecture

Perception and navigation pipeline from camera to autonomous control:

RealSense D455 → /depth, /color, /imu
         ↓
YOLOv8 TensorRT → Custom detection (socks, dirt)
         ↓
3D Detector → Point cloud + floor removal
         ↓
WebSocket Viewer → Real-time 3D visualization

Workflow

1. Detection

RealSense D455 streams 720p RGB + aligned depth at 30 FPS. YOLOv8 (TensorRT) detects objects with custom-trained models achieving 83%+ confidence.

2. Point Cloud Generation

For each detection, crop RGB + depth ROI. Apply D455-optimized filters (spatial, temporal, decimation, hole-filling). Project valid pixels to 3D using camera intrinsics.

3. Floor Plane Removal

Estimate robust floor plane from downsampled depth (4x, 2000+ inliers) using constrained RANSAC. Apply EMA smoothing (α=0.2) for stability. Gate object points above adaptive threshold.

4. Pose Estimation & Visualization

Compute object center from median point cloud coordinates. Publish PointCloud2 messages and stream to WebSocket server for real-time Three.js visualization.

Custom Model Training

Tools for collecting training data and fine-tuning YOLOv8:

  • Data Collection: collectData2DRGB.py captures calibrated images at 1-second intervals
  • Annotation: Images labeled using Roboflow for bounding box annotation
  • Training: YOLOv8 models trained on domain-specific datasets (socks, dirt)
  • Optimization: Models converted to ONNX and compiled to TensorRT for ~10x speedup on Jetson
  • Deployment: Dynamic model loading via ROS2 launch parameters
# Launch with custom model
ros2 launch isaac_ros_examples isaac_ros_examples.launch.py \
  launch_fragments:=realsense_mono_rect_depth,yolov8 \
  model_file_path:=${ISAAC_ROS_WS}/models/yolov8/socks.onnx \
  engine_file_path:=${ISAAC_ROS_WS}/models/yolov8/socks.plan \
  confidence_threshold:=0.83

3D Visualization

Custom WebSocket-based viewer built with Three.js for real-time 3D visualization:

Features:

  • Dual-stream rendering: object-only clouds + full scene context
  • Live 3D center point markers with wireframe spheres
  • Adjustable point size (0.1-15px) via slider
  • Orbit controls (rotate, zoom, pan) with dampening
  • Coordinate axes and ground grid for reference
  • RGB color preservation with sRGB conversion
  • Debug logging panel for status and statistics

Architecture:

web_viewer_server_3d.py subscribes to ROS2 topics and serves data via WebSocket endpoints (/3d, /center, /full_scene). The HTML viewer connects and renders using Three.js with efficient buffer geometry updates at 15+ FPS.

How to Run

# 1. Enter Isaac ROS Docker container
cd ~/workspaces/isaac_ros-dev/src/isaac_ros_common
./scripts/run_dev.sh -d ~/workspaces/isaac_ros-dev

# 2. Source ROS2 workspace
source /opt/ros/humble/setup.bash
source /workspaces/isaac_ros-dev/install/setup.bash

# 3. Launch RealSense + YOLOv8 with D455 optimization
ros2 launch isaac_ros_examples isaac_ros_examples.launch.py \
  launch_fragments:=realsense_mono_rect_depth,yolov8 \
  model_file_path:=${ISAAC_ROS_WS}/models/yolov8/socks.onnx \
  engine_file_path:=${ISAAC_ROS_WS}/models/yolov8/socks.plan \
  confidence_threshold:=0.83

# 4. Run 3D detector node (new terminal)
docker exec -it isaac_ros_dev-aarch64-container bash -c \
  "cd /workspaces/isaac_ros-dev && source install/setup.bash && \
   python3 src/isaac_ros_object_detection/isaac_ros_yolov8/myscripts/yolov8_3d_detector.py"

# 5. Run WebSocket visualization server (new terminal)
docker exec -it isaac_ros_dev-aarch64-container bash -c \
  "cd /workspaces/isaac_ros-dev && source install/setup.bash && \
   python3 src/isaac_ros_object_detection/isaac_ros_yolov8/myscripts/web_viewer_server_3d.py"

# 6. Open viewer.html in browser
# Connect to ws://localhost:8765/3d (point cloud)
#             ws://localhost:8765/center (3D centers)
#             ws://localhost:8765/full_scene (full depth scene)
